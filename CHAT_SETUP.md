## Activate on hosting
1. Deploy the updated frontend AND `api/chat.js` to a host that runs the API, such as the existing Vercel project.
2. In the project's server environment settings, add `NVIDIA_API_KEY` with the actual secret API key generated by NVIDIA. A key ID or key name is NOT the secret. Enter it directly in the hosting dashboard; do not paste it into chat, commit it or add a `VITE_` prefix.
3. Set `NVIDIA_MODEL=z-ai/glm-5.3-flash` and `CHAT_ENABLED=true`. The model is also the server default.
4. Keep the public flag `VITE_CHAT_ENABLED=true` and redeploy. Remove the obsolete `GEMINI_API_KEY`/`GEMINI_MODEL` variables from this app when no longer needed.
5. Open the deployed site, refresh, confirm adult access, then agree to NVIDIA processing before a test message. Check the user's NVIDIA account for model access/quotas if the backend reports a provider error. GET `/api/chat` reports configured availability, not a provider health test.

No key has been installed by the assistant and no live NVIDIA request has been made. Do not commit real keys to `.env.example`; it contains placeholders only. Local Vite supports the same server-only variables, but local credentials should be entered only through a secure facility on the owner's device.

## Existing behavior retained
- Aureatine AI branding and chat layout, immediate shortcut submission, session-only messages, stop/clear controls and reduced motion.
- Adult-only access remains a product choice; changing provider does not enable minors. Calculator accepts the existing 18–75 range and keeps editable-age validation.
- Calculator math runs locally; optional AI explanations require separate consent and server-side recalculation. Browser-supplied targets are not trusted.
- No account/balance access or point-awarding tools. No chat persistence or intentional prompt logging in this app. NVIDIA and hosting infrastructure have their own processing policies; this does NOT claim zero provider retention.
- Same-origin check, size/message limits, six requests/minute best-effort per-process IP throttle and a 20-second upstream timeout. Serverless instances do not share this throttle; production needs appropriate platform abuse controls.
- New requests must declare the NVIDIA provider; old cached Gemini clients are rejected before forwarding, requiring a refresh and new consent. This is not identity/age assurance.
- Only final `choices[0].message.content` is returned. Reasoning metadata and think blocks are not displayed; empty answers show a retry error. Provider errors do not reveal secrets or raw response bodies.

## Streaming latency fix — prepared after deployment 91b6d61
The preceding NVIDIA version was successfully published to GitHub/Vercel and a live greeting returned HTTP 200. A later live one-sentence request timed out at approximately 20.28 seconds. These observations do not establish constant model latency or identify the provider-side cause.

This new, NOT-YET-PUBLISHED fix uses real SSE streaming for the Vercel frontend/backend. It forwards only final-answer content deltas, never reasoning metadata; a split-tag filter suppresses think/analysis blocks across chunk boundaries. No simulated typewriter animation remains. The UI batches paints at 40ms, preserves/labells incomplete answers, handles Stop/Clear, and retains JSON compatibility for an older backend. Stop/disconnect aborts the upstream request when the host delivers the response-close event.

Ordinary requests now have a 384-token output budget, calculator explanations 768; repetitive system instructions were reduced while retaining medical/privacy/age and calculation safeguards. Length-limited answers are explicitly marked rather than presented as complete. NVIDIA may spend time before producing its first answer token: streaming improves time-to-visible-text once answer tokens exist but cannot guarantee a fast first token or prevent provider load delays. No unsupported model-specific reasoning switch or automatic provider fallback was added. Existing 20-second upstream and 25-second client limits remain; no silent retry consumes extra quota.

`checks/chat-stream.mjs` proves incremental backend chunks are written before completion, with filtering, truncation, malformed/ended stream handling and abort propagation. `checks/chat-stream-browser.cjs` proves early browser display, no typewriter delay, Stop, partial-answer labels, clear behavior, JSON fallback and 320/390/1440 layouts using mocked streams. AI Slop targeted scan: 0 errors, 4 remaining warnings (semantic roles, keyboard handler and fixed provider URL); the fixed NVIDIA endpoint is retained intentionally to avoid forwarding secrets to arbitrary URLs.

The optional Supabase single-file adapter was regenerated for parity but remains a buffered JSON transport. The selected production hosting remains Vercel.
